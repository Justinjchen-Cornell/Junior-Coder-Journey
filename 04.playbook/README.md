> 记录标准的出口："能教给别人"的东西放这里。

## 格式（每篇玩法一页）

```markdown
# 玩法名
## 适合年龄
## 材料（尽量 0 成本）
## 玩法步骤（3-5 步，爸爸当机器人的说法用「」标出）
## 真实反应（来自 episodes 的观察摘录）
## 失败复盘（什么情况下孩子没兴趣了）
```
