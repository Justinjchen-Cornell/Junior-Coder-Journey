# 🐒 小猴子找朋友

> 给小宥宥的 BFS 思维游戏——**按「扩散」，看波纹一圈圈亮，目标在第几圈=几步！**

## 怎么玩（就一个按钮）

1. 按「🌊 扩散下一圈」——森林里一圈小动物亮起来（波纹！）
2. 继续按，直到**会做冰淇淋的朋友（🍨）**出现
3. "第 N 圈找到 = N 步"——**这就是最短路径！**

- 🍼 宝宝模式：小森林 6-8 只，纯看波纹
- 🚀 挑战模式：大森林 12-16 只，可以**提前猜**："我觉得目标就在刚亮的圈里！"（猜对提前赢，猜错多试一圈）

## 给爸爸的话（教学点）

- 一圈一圈 = BFS 层级；**先碰到谁谁就最近 = 最短路径**
- 结算彩蛋："如果一条路走到黑（DFS），可能会绕远路哦！"
- 挑战的"猜" = 主动观察的奖励
- 问孩子："为什么第一圈就亮的动物，一定比第三圈才亮的近？"——他自己按出来的
