## 1. 一句话定位

> 让孩子点"扩散"，亲眼看到波纹一圈圈向外扩——目标在第几圈出现，就是几步路。
> BFS 的"先到先得 = 最短"不是讲出来的，是孩子数出来的。

## 2. 核心动作（跟着算法走）

- 森林关系图（SVG）：节点=小动物，连线=认识
- 「扩散下一圈」按钮 = 波纹推进：当前圈全部亮起（发光动画 + 圈号徽章）
- 目标 = 会做冰淇淋的动物（隐藏 🍨，扩散到时揭示）
- 找到：显示"第 N 圈找到 = N 步（最短！）"

## 3. 双模式

| | 🍼 宝宝模式 | 🚀 挑战模式 |
|---|---|---|
| 图规模 | 6-8 节点，目标 2-3 圈 | 12-16 节点，目标 3-5 圈 |
| 交互 | 只按「扩散」按钮 | 同左 + **提前猜目标**（点节点猜：对=提前胜利，错=错误） |
| 教学点 | 波纹层数 = 步数 | BFS 先到先得 = 最短；猜错提示观察 |
| 星级 | 0 错=3 / ≤2 错=2 / 其他=1 | 同左 |
| 纪录 | localStorage 最少圈数 | 同左 |

## 4. 教学点

- 一圈一圈 = BFS 层级；先碰到目标 = 最短路径
- 对比彩蛋："如果是往一条路走到黑（DFS），可能绕远路"
- 挑战"猜目标" = 主动观察的奖励

## 5. 技术（系列同构 + 版本化文件名）
- js/game.1.0.js：`createBFSGame(mode)` → `expand()/guess(id)/getStats()/reset()`
