## 英文版（7 条线程）

```
1/7 I'm a 42-year-old dad. My son is 3.5. I didn't teach him to code — I turned 10 classic algorithms into web games he actually plays. Zero install, runs in any browser. A thread 🧵

2/7 The realization: at 3, kids can't learn programming. But they CAN play algorithms. "Guess a number, each try cuts it in half" beats "this is binary search" every time.

3/7 So I built one game per algorithm:
🎮 Binary search = find the hiding animal (≤7 tries)
🪆 Recursion = nesting dolls, open to the empty one, count back out
🐜 Dijkstra = compare step numbers, pick the nearest junction

4/7 The tech: plain HTML/CSS/JS, zero dependencies. Every game's logic is unit-tested — my Dijkstra has to match brute-force enumeration on random graphs. Playwright smoke tests play the whole flow like a kid would.

5/7 My favorite bug: I designed a "greedy trap" for the tower game with 4 villages. Tests proved it's mathematically impossible — a real counterexample needs ≥8 elements. Rebuilt it, brute-force verified. This is what "educational" should mean.

6/7 Each algorithm also has a bedtime story + a printable activity card (no screen). The whole thing is CC BY-NC, free for families. Open source, good-first-issues included.

7/7 Play now — no signup, no install:
justinjchen-cornell.github.io/Junior-Coder-Journey/
GitHub: github.com/Justinjchen-Cornell/Junior-Coder-Journey
If you have a 3-7yo, the activity cards PDF is the fastest win. 🧸
```
