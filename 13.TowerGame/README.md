# 📡 盖广播塔（贪心）

> 给小宥宥的贪心思维游戏——**每次选"还能盖最多村"的塔，看贪心什么时候赢、什么时候被骗！**

## 怎么玩

1. 选关卡（🌱 5 村 / 🌿 8 村有陷阱 / 🌳 12 村大挑战）
2. **点塔盖下去** → 覆盖的村庄亮起 📶
3. 塔上的角标提示"还能盖 N 村"——试试每次都选最大的！
4. 盖错了？「↩️ 拆掉上一座」随便反悔
5. 全部村庄亮起 = 完成 → 对比最优解

## 给爸爸的话（教学点）

- 每次都选"覆盖最多" = **贪心算法**——第 1 关它刚好最优（建立直觉）
- **第 2 关陷阱**：大塔盖 6 村骗贪心，最优只要 2 座互补塔——"贪心被骗啦！"
- 结算对比：你用了 X 座 vs 贪心 Y 座 vs 最优 Z 座 + 最优塔金圈
- 彩蛋："有些问题（NP 完全）连电脑也只能'差不多'——工程上接受近似！"
- 问孩子："先盖最大的塔，一定是最少塔吗？"——他自己试出来的
