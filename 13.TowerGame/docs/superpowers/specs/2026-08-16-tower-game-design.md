# 《盖广播塔》设计文档

- 日期：2026-08-16
- 状态：已批准（算法森林系列 · 第 8 章 贪心）
- 项目：Junior-Coder-Journey / 13.TowerGame

## 1. 一句话定位

> 小佑佑的工程队要在草原盖信号塔，让所有村庄都有信号。
> 孩子点塔盖下去（覆盖圈亮起）——自然学会"每次选覆盖最多的"（贪心），
> 第 2 关的陷阱让他亲眼看见：**贪心有时候会翻车，最优需要"算总账"**。

## 2. 核心机制（一个交互）

- 点候选塔 → 盖下去 → 覆盖的村庄亮起
- 塔上显示"还能盖 N 村"（贪心提示：选数字最大的！）
- 「拆掉上一座」= 悔棋（孩子自由试错）
- 全部村庄亮起 = 完成

## 3. 三关递增（陷阱 = 设计出来的）

| 关 | 村庄/塔 | 结构 | 教学 |
|---|---|---|---|
| 1 | 5 村 4 塔 | 贪心 = 最优（2 座） | 建立"选最多"直觉 |
| 2 | 8 村 6 塔 | **贪心翻车**：大塔 G(6村) 骗贪心 → 贪心 3 座 vs 最优 2 座 | "大塔骗了你！" |
| 3 | 12 村 8 塔 | 大陷阱：贪心 3 座 vs 最优 2 座（+诱饵） | 近似比 + NP 完全彩蛋 |

- 结算：你用了 X 座 vs 最优 Y 座 + 最优解金圈显示
- 彩蛋："贪心大多数时候赢，有时候差一点——这就是为什么电脑也只能'差不多'（NP 完全）"

## 4. 视觉（一次设计到位）

- SVG 草原地图：村庄 🏠 圆点、候选塔 🗼 + 半透明信号圈
- 盖塔：塔变彩 + 覆盖村庄亮起 + 信号波纹动画
- 塔角标："还能盖 N 村"（贪心引导）
- 最优解金圈（结算时）

## 5. 星级与纪录

- 塔数 = 最优 → 3⭐ / ≤最优+1 → 2⭐ / 其他 1⭐
- 每关纪录（最少塔数）；三关全通庆祝
- 回游乐场 + 奖励评价（系列标准件）

## 6. 技术（系列同构 + 版本化文件名）

- js/game.1.0.js：`createTowerGame(level)` → `chooseTower(id)/undo()/getStats()/reset()`
- 最优 = 暴力枚举（小规模 2^n）；贪心 = 标准模拟（对比用）
- 单元测试（三关结构/贪心翻车验证/暴力最优/undo/星级）+ Edge 冒烟
- 门户卡片点亮（第 8 个）

## 7. 成功标准

- 孩子能独立通关三关，第 2 关发现"先盖大塔反而吃亏"
- 玩完能说"每次都选最多的，有时候不是最好的"
- 单元测试全绿 + 冒烟全过 + Pages 可玩
