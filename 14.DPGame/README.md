# 🐿️ 小松鼠装松果（动态规划）

> 给小宥宥的 DP 思维游戏——**篮子只有这么大，试装出最高的价值！**

## 怎么玩

1. 选关卡（🌱 4 格 / 🌿 5 格有陷阱 / 🌳 7 格大挑战）
2. **点松果装进篮子**（看 ⚖️ 重量 ⭐ 价值）→ 再点拿出来
3. 超重？篮子会晃动提示"先取出一些吧"
4. 「🎒 装好了！」→ 结算对比 + **DP 格子表动画**

## 给爸爸的话（教学点）

- 每个物品只有两个选择：**放 or 不放**——取更好的
- **第 2 关陷阱**：先拿最值钱的大蘑菇（34）只剩 39；🌰+🍒+🫐 三个小件 = 45！
- 结算的**格子表**：每格 = "这个容量最多能装多少"——格子踩着前一格 = DP 递推
- 三重对比：你装的 ⭐ vs 贪心会得 ⭐ vs 最优 ⭐
- 问孩子："为什么光拿最值钱的不够？"——他自己试出来的
