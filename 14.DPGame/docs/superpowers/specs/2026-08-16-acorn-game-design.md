# 《小松鼠装松果》设计文档

- 日期：2026-08-16
- 状态：已批准（算法森林系列 · 第 9 章 动态规划）
- 项目：Junior-Coder-Journey / 14.DPGame

## 1. 一句话定位

> 小松鼠的篮子容量有限，每件松果有"重量"和"价值"（松子数）。
> 孩子试装（放/取）→ 看总价值 → 结算对比最优 + **DP 网格填表动画**。
> "放 or 不放，取更好的"——孩子亲手试出来的最优，就是 DP 递推。

## 2. 核心机制（一个交互）

- 点物品 → 放进篮子（占用重量格）→ 再点 → 取出
- 篮子容量条可视化（格点亮）；超重 → 篮子晃动 + 提示取出
- 「🎒 装好了！」按钮 → 结算
- 结算：你的价值 vs 最优（DP）+ 最优组合 + **网格填表动画**（容量 1..C 逐格亮起，看递推）

## 3. 三关递增（陷阱 = 设计出来的）

| 关 | 篮子/物品 | 结构 | 教学 |
|---|---|---|---|
| 1 | 4 格 / 3 件 | 最优好找 | 试装体验 |
| 2 | 5 格 / 4 件 | **贪心陷阱**：大件(3格30) vs 两中件(2+2格 20+20=40) | "先拿大的反而亏！" |
| 3 | 7 格 / 6 件 | 更多组合 + 诱饵 | 网格动画 + "格子踩着前一格" |

- 最优 = DP 表；贪心 = 按价值密度模拟（对比用）
- 星级：价值=最优 3⭐ / ≥90% 2⭐ / 其他 1⭐

## 4. 视觉（一次设计到位）

- 物品卡片：emoji + 重量（⚖️N 格）+ 价值（⭐N）
- 篮子：容量格条（0..C），占用格点亮，满格晃动
- 物品飞入篮子动画；结算 DP 网格逐格填表动画

## 5. 结算与纪录

- 你装的价值 vs 最优 + 最优组合展示
- "贪心（先拿大的）会得到 X，DP 找到最优 Y——格子踩着前一格就是秘密"
- 每关纪录（最优价值达成与否）；三关全通庆祝；回游乐场 + 奖励评价

## 6. 技术（系列同构 + 版本化文件名）

- js/game.1.0.js：`createAcornGame(level)` → `toggleItem(id)/finish()/getStats()/reset()`
- DP 表 + 回溯最优组合；贪心模拟（密度）；暴力对拍验证
- 单元测试 + Edge 冒烟；门户卡片点亮（第 9 个）

## 7. 成功标准

- 孩子能独立通关三关，第 2 关发现"两个中件比一个大件值"
- 玩完能说"装东西要想总账，不能光看单个大的"
- 单元测试全绿 + 冒烟全过 + Pages 可玩
