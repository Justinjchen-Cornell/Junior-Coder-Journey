## 1. 背景与目标

小宥宥（3 岁半）的编程启蒙路线正处于"🌱 无屏期 → 故事+游戏"阶段。
本游戏是把亲子课堂《01 二分查找》的"猜数字擂台"游戏网页化、故事化、可视化：

- **给 3-4 岁**：宝宝模式（1-10），超大按钮，纯快乐 + 听反馈
- **给 5-7 岁**：挑战模式（1-100），区间高亮可视化，≤7 步三星挑战
- **教学目标**：让孩子亲眼看见"每次砍掉一半"，玩 3 局后能说出"猜中间，最多 7 次"

## 2. 核心决策（头脑风暴结论）

## 3. 玩法设计

### 3.1 宝宝模式（1-10）
- 画面：10 棵树的树洞（🌳 大图标），动物藏在其中一个
- 输入：点击树洞按钮（≥64px 大按钮）
- 反馈：猜错 → "不是 5 号洞……它在**更高**的树洞里哦 🐿️"（方向提示大字 + 动物表情）；猜对 → 动物跳出 + 彩带 + 音效
- 可视化：猜过的树洞变灰，剩余树洞发光
- 无失败压力，纯快乐

### 3.2 挑战模式（1-100）
- 画面：100 格数字板（10×10 网格，手机可滚动）
- 输入：点击格子 + 可选数字键盘
- 反馈：同左 + **搜索区间 [lo, hi] 高亮发光**，排除区变暗
- 计步：实时显示"第 N 次尝试"
- 星级：≤7 步 = ⭐⭐⭐（二分最优）；≤10 = ⭐⭐；其他 = ⭐
- 纪录：localStorage 存最少步数 + 星级；破纪录 → 庆祝动画

### 3.3 故事包装
1. 开场选动物：🐰🐻🦊🐱🐸（"今天谁躲起来了？"）
2. 猜树洞 = 猜数字
3. 猜对庆祝：动物跳出 + emoji 彩带 + Web Audio 合成音效（零外部资源）

## 4. 技术设计

### 4.1 文件结构
```
06.BinarySearchGame/
├── index.html          # 单页，中文，响应式
├── css/style.css       # 卡通圆角风，大按钮，高对比
├── js/game.js          # 纯逻辑：状态机 + 猜数判断（零 DOM）
├── js/ui.js            # DOM 渲染：树洞/格子/高亮/音效/纪录
├── test/game.test.js   # node --test 单元测试（零依赖）
├── docs/superpowers/specs/2026-08-16-binary-search-game-design.md
└── README.md           # 玩法说明（可爱版）
```

### 4.2 game.js 逻辑接口（可测试核心）
```js
createGame(mode)            // mode: 'baby'(1-10) | 'challenge'(1-100)
  → { min, max, target, guessCount, state }
game.guess(number)
  → { result: 'low'|'high'|'hit', guessCount, range: {lo, hi}, done }
game.getRange()             // 当前搜索区间（供 UI 高亮）
game.reset()
```
纯函数式核心，无 DOM、无全局状态污染，可被 Node 直接测试。

### 4.3 UI 要点
- 大按钮 ≥64px，触屏友好
- 高对比配色（深底亮字 + 亮色高亮），儿童视力友好
- 响应式：手机竖屏（10 列树洞/格子自适应）
- 音效：Web Audio API 合成（正确音/错误音/庆祝音），不引外部文件
- localStorage：最佳纪录（key: `bsg-best-<mode>-<animal>`）

## 5. 测试计划（TDD）
1. createGame 初始化（范围、target 在范围内、步数为 0）
2. guess 命中 / 大了 / 小了（含边界 1 和 100）
3. 区间计算正确（每次砍半）
4. 连续猜直到命中，步数 ≤ ceil(log2(n))
5. reset 正确重置
6. 所有动物选择不影响逻辑（参数化）
