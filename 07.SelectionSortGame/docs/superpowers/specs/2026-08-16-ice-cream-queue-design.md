## 1. 一句话定位

> 让孩子**亲手排一次队**，再亲眼看到"同一张牌被看了一遍又一遍"——
> 累过一次，就懂 O(n²)。选择排序的教学即游戏本体。

## 2. 世界观（与第一章同一"小动物森林"）

小动物们乱糟糟地排队买冰淇淋，孩子帮老板把队伍按"身高"排整齐。
每张小动物牌 = 一个动物 + 数字身高（动物高矮 = 数字大小，3 岁半看不懂数字也能玩）。

## 3. 双模式设计

### 🍼 宝宝模式（3-4 岁）—— 方案 A：全可见·选最小
- 5~8 张小动物牌**全部亮着**，乱序排队
- 每轮任务："谁最矮？点它！" → 点对，小动物"啪嗒"跳进已排序队伍首位
- **扫描动画（教学核心）**：选完后一道光扫过所有剩余牌，每张被扫到的牌头顶冒一个 `👀`
  - 👀 计数**跨轮累积**：同一张牌被看第 2 次、第 3 次……孩子亲眼看到"它被看了好多遍"
- 点错不惩罚：温柔提示"再看看，还有更矮的哦～"（错误归给机器人原则）
- 星级：0 错 ⭐⭐⭐ / ≤2 错 ⭐⭐ / 其他 ⭐

### 🚀 挑战模式（5-7 岁）—— 方案 B：翻牌记忆
- 8~12 张牌**背面朝上**，一次翻一张看，看完翻回去
- 找到记忆中的最小 → 点它"确认" → 正确则飞入队伍
- **翻牌次数 = 分数**（找最小必须"记住所有看过的"→ 重复扫描的真实负担）
- 排完统计页：
  - 总翻牌次数 vs 理论值（n²/2 附近）
  - **"每张牌被你看了 N 次"条形图**（孩子发现每张都被看了好多遍）
  - **数字爆炸表**：5 张=10 次 / 8 张=28 次 / 12 张=66 次 → O(n²) 体感
- 星级：翻牌 ≤ 理论×1.2 ⭐⭐⭐ / ×1.5 ⭐⭐ / 其他 ⭐
- 教学彩蛋："原来排队这么累！"文案

## 4. 让它"好玩"的设计点

1. **物理感**：点对的小动物弹跳飞入队伍；队伍从乱到齐 = 可视进度
2. **错误宽容**：只提示不惩罚（宝宝模式）
3. **统计彩蛋**：每张牌的 👀 计数 + 条形图 + 数字爆炸表
4. **纪录**：localStorage 存最佳（翻牌次数/星级），破纪录 🏆
5. **音效**：Web Audio 合成（选对叮/选错嘟/胜利琶音）

### game.js 接口（TDD 契约）
```js
createQueueGame(mode)              // 'baby'(5-8张) | 'challenge'(8-12张)
  → { cards: [{id, value}], ... }
game.checkMin(id)                  // 宝宝模式：点一张牌判断是否当前最小
game.flip(id)                      // 挑战模式：翻牌（计入 flipCount）
game.confirm(id)                   // 挑战模式：确认"这是最小"
game.getStats()                    // { scans/flips, theoretical, stars }
game.reset()
```
- shuffle：Fisher-Yates（可测：排列随机 + 完整包含）
- 选择排序核心：每轮找最小 → 移入已排序区 → 扫描动画计数
- 星级规则纯函数（可测）

## 6. 测试计划
1. Fisher-Yates shuffle：包含全部元素、可重复
2. checkMin：当前最小 = true，非最小 = false
3. flip：翻牌次数递增、已翻开状态
4. confirm：正确/错误分支
5. 星级边界（0 错/2 错/3 错；翻牌 1.2x/1.5x）
6. getStats 数字正确（n 张 → 理论比较 n(n-1)/2）
