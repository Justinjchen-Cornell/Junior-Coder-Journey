# 🪆 套娃拆拆乐

> 给小宥宥的递归思维游戏——**拆（压栈）+ 数回来（弹栈）+ 空娃娃（基线）**。

## 怎么玩

1. 点「打开」拆套娃：一层、两层、三层……越拆越小
2. 拆到**最小的空娃娃** ✨——"里面什么也没有，到底啦！"
3. **数回来**：从最小的开始往外数，最后答"一共几层？"

两个模式：

- 🍼 **宝宝模式**：5~7 层，系统帮你数回来，你答总数
- 🚀 **挑战模式**：8~10 层，每层有数字牌，你要按"从里到外"的顺序点出来

## 给爸爸的话（教学点）

- 拆 = **递归下降**（一层层压栈记住）；数回来 = **回溯**（弹栈，后进先出）
- 最小的空娃娃 = **基线条件**——没有它，套娃永远拆不完（程序永远停不下来）
- 问孩子："为什么数回来的时候，最里面的数字先出来？"——这就是栈！
