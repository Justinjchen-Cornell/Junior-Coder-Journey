# 《套娃拆拆乐》设计文档

- 日期：2026-08-16

## 1. 一句话定位

> 把递归的两个动作——**拆（递归下降/压栈）**和**数回来（回溯/弹栈）**——变成孩子亲手玩的游戏。
> 拆到"最小的空娃娃"= 基线条件；从里往外数回来 = 递归返回。

## 2. 世界观

小松鼠攒了一摞套娃（小动物森林世界观）。孩子帮它拆开、再数回来。

## 3. 玩法

### 阶段一：拆（递归下降）
- 屏幕上一摞套娃，只能看到最外层
- 点「打开」→ 外层拆开动画 → 里面的套娃出现（系统"记住"这一层 = 压栈）
- 一直拆到**最小的空娃娃** → ✨ 基线闪光："最小的娃娃是空的——到底啦！"

### 阶段二：回溯（递归上升）
- 🍼 宝宝模式：系统动画从里往外"数回来"（1、2、3…N），最后孩子答"一共几层？"（3 个选项）
- 🚀 挑战模式：每层套娃上有**数字牌**，孩子拆时记住，回溯时按"从里到外"的顺序点数字（点错温柔提示）

### 教学点
- 空娃娃 = 基线条件（递归的"刹车"）
- "数回来"的顺序 = 递归返回的顺序（后进先出 = 栈！）

## 4. 双模式

| | 🍼 宝宝模式 | 🚀 挑战模式 |
|---|---|---|
| 层数 | 5-7 层（显示层号） | 8-10 层（乱序数字牌） |
| 回溯 | 系统动画数回来 + 3 选 1 答层数 | 孩子按"从里到外"顺序点数字 |
| 星级 | 0 错 ⭐⭐⭐ / ≤2 错 ⭐⭐ / 其他 ⭐ | 同左（错误=点错顺序） |
| 纪录 | localStorage：最少错误 | 同左 |

## 6. 成功标准
- 宝宝模式：3 岁半能独立"点打开→看动画→答层数"
- 挑战模式：5-7 岁玩完能说"拆到底才知道一共有几层——像套娃一样一层层回去"
