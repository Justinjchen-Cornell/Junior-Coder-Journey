# BFS 广度优先搜索 · 教给别人版

## 给 8 岁孩子讲的版本

> 往池塘扔一块石头，波纹一圈一圈往外扩——先碰到岸的一定是**最近**的波纹。
> BFS 就是"水波纹找路法"：先查离你最近的一圈人，再查第二圈、第三圈……
> 所以它找到的路**一定是最短的**。
> 为什么能保证？因为它用**排队**（先来先查）——你同桌排在你前面，一定比你朋友的朋友先被问到。

## 给大人讲的版本

- **图（graph）= 节点 + 边**：朋友网络、地铁线路、网页链接，全是图
- **BFS 解决两类问题**：① 有没有路？② 哪条路最短？（无权图）
- **引擎是队列（FIFO）**：先入队的先处理 → 保证按"距离层"逐层推进
- **复杂度 O(V+E)**：每个节点入队一次，每条边被看一次——线性
- **与 DFS 的唯一区别**：队列 vs 栈（递归）——一个横着铺开，一个竖着钻底
- **实测**（benchmark.py）：
  - 同图 BFS 2 步 vs DFS 9 步（DFS 走到底才回头）
  - 10 万人随机社交网络：平均"认识链" **6.6 跳 = 六度分隔实测成立**（理论 lnN/lnd ≈ 4.6，同量级）

## 代码逐行（solution.py 核心）

```python
def bfs_shortest_path(graph, start, target):
    q = Queue(); q.push(start)      # ① 队列：起点入队
    visited = {start}               # ② 去过的地方（防环死循环）
    parent = {start: None}          # ③ 记录"谁带我来的"→ 回溯用

    while q:                        # 队列不空就一直扩
        node = q.pop()              #    队头 = 当前距离层最近者
        for nb in graph.get(node, []):
            if nb not in visited:
                visited.add(nb)
                parent[nb] = node
                if nb == target:
                    return _trace_back(parent, target)  # 首次碰到=最短
                q.push(nb)          #    下一层入队（波纹外扩）
    return None                     # 队列空了还没找到 → 不可达
```

## 三个经典坑

1. **忘记 visited → 死循环**：图有环（A→B→A），不标记会永远转圈
2. **队列写成栈 → 变成 DFS**：popleft 换成 pop，最短路径保证就没了（实测 2 步变 9 步）
3. **判断时机**：在**入队时**标记 visited 而不是出队时——否则同一节点可能被入队多次（多层重复）

## 生活应用

- 导航最短路径（无权简化版）、拼车配对
- 微信"六度分隔"、职场人脉最短链（LinkedIn 二度人脉）
- 网页爬虫分层抓取、垃圾信息传播层级追溯

## 一句话总结

> **BFS = 队列 + 去重 + 层级推进。** 找"最短"的通用方法，也是 Dijkstra（第 7 章）的序曲——把"无权图"换成"有权图"，队列换成优先队列，就是下一章。
