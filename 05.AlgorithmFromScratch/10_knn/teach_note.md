# KNN K 最近邻 · 教给别人版

## 给 8 岁孩子讲的版本

> 有个新同学转学来，老师想知道他喜欢玩什么。
> 最好的办法：看他**最要好的 3 个朋友**喜欢玩什么——朋友们玩什么，他多半也喜欢。
> 这就是 KNN（K 最近邻）：**想知道一个新东西是什么，看和它最像的 K 个老东西是什么**。
> "像"就是"近"：体重、个子、喜欢的东西越像，就越近。
> 3 个朋友里有 2 个爱踢球 → 他大概也爱踢球。就这么简单！

## 给大人讲的版本

- **直觉**：物以类聚。KNN 是**机器学习的第一课**，也是"懒惰学习"的代表
- **三个零件**：距离函数（欧几里得 = 勾股定理 n 维推广）→ 找 K 个最近邻居 → 投票（分类）/ 平均（回归）
- **分类 vs 回归**：邻居"投票"（最多数）→ 类别；邻居"平均"（求均值）→ 数值
- **升级**：加权投票（票 = 1/距离）——实测：近处孤立点，普通投票被密集邻居带偏，加权后正确
- **K 值调参**（实测）：k=5 甜点位 97.7%；k=1 过拟合（噪声敏感）；k=50 边界被抹平（96.3%）——**数据说话**
- **距离度量**：欧几里得/曼哈顿对"数值大小"敏感；**余弦**只看方向（喜好模式），对打分尺度免疫——推荐系统常用
- **懒惰学习的代价**（实测）：样本 ×10 → 预测 ×10（O(n·d)）。零训练成本，但每次预测扫全库 → 大数据用 KD 树/向量索引
- **特征工程**：KNN 的好坏全在特征选择——"高矮胖瘦"选对了才有区分度（书里柚子 vs 橙子按"重量×颜色"一刀切）

## 代码逐行（solution.py 核心）

```python
def knn_classify(data, point, k=3):
    neighbors = sorted(data, key=lambda d: euclidean(d[0], point))[:k]
    votes = {}
    for _, label in neighbors:
        votes[label] = votes.get(label, 0) + 1
    return max(votes.items(), key=lambda v: v[1])[0]
```

## 三个经典坑

1. **特征没归一化**：重量(克)和颜色(0-1)不在一个量级 → 重量主导距离，颜色白搭（真实项目先标准化）
2. **K 选错**：太小过拟合（噪声），太大抹平边界——交叉验证选 K
3. **维数灾难**：特征维度太高 → 所有点都"一样远"（高维空间距离坍缩）→ 先降维

## 金融/量化连接

- **相似策略聚类**：找"和自己持仓最像"的基金/组合（KNN 的金融版）
- **信用评分/风控**：新客户 vs 历史违约客户的距离
