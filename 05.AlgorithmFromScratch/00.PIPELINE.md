# 从零实现流水线（Karpathy 风格 × 陈嘉版）

> "What I cannot create, I do not understand." — Feynman

每章五步，顺序执行，**数据不会说谎**：

1. **跑通** — 运行参考代码，先观察行为，不急着懂原理
2. **测速** — 用大输入实测，建立"快/慢"直觉（复杂度是测出来的，不是背出来的）
3. **从零实现** — 合上参考，自己写（写不出来=还没懂）
4. **验证** — 随机属性测试 + 与参考实现对拍 + 步骤计数
5. **教给别人** — 用类比 + 代码 + 复杂度写成"能教给 8 岁孩子"的笔记（教是最好的学）

## 目录约定

- `reference.py` — 参考实现（官方/书中代码，跑通用）
- `practice.py` — 练习脚手架（空白函数 + 测试，**你的手写区**）
- `solution.py` — 从零实现（本次流水线的产物）
- `teach_note.md` — 教给别人版笔记（每章必产）

## 验收标准

- [ ] solution.py 通过全部测试
- [ ] 步骤计数符合理论复杂度（二分 ≤ ceil(log₂n)，选择排序 ≈ n²/2）
- [ ] teach_note.md 写完，并能口头讲出来
