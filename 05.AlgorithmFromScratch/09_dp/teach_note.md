# 动态规划 · 教给别人版

## 给 8 岁孩子讲的版本

> 小松鼠要冬眠了，篮子只有 4 格大。它有三个宝贝：大松果（3 格，30 个松子）、中松果（2 格，20 个）、中松果（2 格，20 个）。
> 贪心的小松鼠先拿"最重的"大松果——篮子只剩 1 格，啥也装不下了，只有 30 个松子。
> 聪明的办法：拿一张**格子纸**，一格一格地试——"如果篮子只有 1 格、2 格、3 格、4 格，我该怎么装？"
> 每填一格，都看看"上一格的最佳答案"，再加"新宝贝+剩下的格子"。填到最后——哇，两个中松果 = 40 个松子！
> 这就是**动态规划**：把大问题拆成一排小格子，一格一格踩着前面的答案往上爬。

## 给大人讲的版本

- **直觉**：数独填格子。**网格 = 决策表**：行 = 前 i 个物品，列 = 容量 j
- **递推公式（背包的全部秘密）**：
  ```
  cell[i][j] = max( cell[i-1][j],            # 不放：沿用上一行
                    value[i] + cell[i-1][j-w[i]] )  # 放：腾出空间 + 新价值
  ```
  每个格子只有两个选择——"放"或"不放"——取大的
- **回溯**：从右下角倒推，`dp[i][j] != dp[i-1][j]` 说明选了物品 i
- **与贪心的关系**（呼应第 8 章）：贪心=近似（实测平均亏 2.1%、最坏亏 40%）；DP=**精确最优**——用"空间"换"时间"
- **复杂度**：O(n×容量)——网格大小。**伪多项式**：不是真 NP（容量小时飞快，容量大时爆炸）
- **LCS（最长公共子序列）**：同样网格，不同递推——字符相同斜对角+1，不同取上下较大。**是 diff/git 合并/DNA 比对/拼写纠错的祖宗**
- **经典应用**：背包（装箱/预算分配）、LCS（版本控制）、编辑距离（拼写纠错）、最长递增子序列、路径计数

## 三个经典坑

1. **公式写反**：`dp[i-1][cap-w]` 是"上一行"不是"本行"——同一物品只能用一次（0/1 背包）
2. **回溯条件**：`dp[i][j] != dp[i-1][j]` 判断"选了"——相等说明没选（沿用上行）
3. **维度对齐**：行=物品、列=容量，`dp` 初始化要 `(n+1)×(cap+1)`，索引别错位

## 金融连接

- **投资组合 = 高维背包**：预算约束下的资产配置最大化收益——就是背包的变体
- **分仓决策**：每笔仓位的"价值/风险"密度排序 = 贪心直觉；但全局最优要 DP/ILP
- **回测里的 DP**：最优执行路径、状态机策略、期权定价（二叉树 = 网格 DP）

## 一句话总结

> **动态规划 = 把"决策"画成网格，每格踩在前一格肩膀上。**
> 贪心问"眼前哪个好"，DP 问"所有子问题都解决了，现在哪个好"——**前者是直觉，后者是证明。**
