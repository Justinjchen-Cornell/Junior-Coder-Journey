# 🐷 小猪省钱路（含 🚜 工程队送货模式）

> 给小宥宥的 Dijkstra 思维游戏——**每次都去最便宜的一站，价格面板自己会更新！**

## 三个模式

- 🍼 **宝宝模式**：小猪从 🏠 家去 🏫 学校，点相邻的路走，数硬币——试试哪条路最省！
- 🚀 **挑战模式**：Dijkstra 操作台——点价格最小的站（贪心）→ 定案 ✅ → 邻居价格变小（松弛）
- 🚜 **工程队送货模式**（神奇的本子 = 优先队列）：
  - 小佑佑的工程队从 🚜 基地送货到 🏗️ 工地，地图标公里数
  - **神奇的本子**自动把最近的基地排最前（第一行 👆）
  - 处理第一行 → 公里数更新（松弛）→ 本子重排，数字"跳"上来！
  - 直到工地排第一行 → 总公里数！

## 给爸爸的话（教学点）

- 贪心（选最便宜）+ 松弛（更新邻居）+ 定案（✅不再变）= Dijkstra 三步
- 工程队模式 = **优先队列可视化**：第一行 = 当前最近，重排动画 = 松弛
- 结算彩蛋："如果有一条路'倒贴钱'（负权），这个方法会失灵——现实世界没有这种路"
- 问孩子："为什么每次都处理本子第一行，最后一定是最短的？"——他自己操作出来的
