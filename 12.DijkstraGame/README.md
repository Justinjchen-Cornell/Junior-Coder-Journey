# 🚜 工程队送货路（Dijkstra）

> 给小宥宥的 Dijkstra 思维游戏——**小佑佑的工程队送货，用"神奇的本子"规划公里数最少的路线！**

## 怎么玩

- 🍼 **宝宝模式**：从 🚜 基地到 🏗️ 工地，点相邻的路走，数公里——试试哪条路最近！
- 🚀 **挑战模式（神奇的本子 = 优先队列）**：
  1. 本子上写着已发现的基地，**自动把最近的排最前面**（第一行有 👆）
  2. 每次都处理第一行（贪心！）→ 它定案 ✅
  3. 到了新基地，邻居的公里数可能**变小**（松弛）→ 本子自动重排，数字"跳"上来！
  4. 直到 🏗️ 工地排到第一行 → 处理它 → 总公里数！

## 给爸爸的话（教学点）

- 本子 = **优先队列**：自动排序，第一行 = 当前最近（贪心选择）
- 松弛 = 公里数变小 → 本子重排的可视化（"7号从 8 公里变 5 公里，跳上来了！"）
- 贪心在非负权下就是最优——"绝不回头，因为前面的路只会越来越远"
- 结算彩蛋：负权（倒贴公里）会破坏这个智慧——现实世界没有这种路
