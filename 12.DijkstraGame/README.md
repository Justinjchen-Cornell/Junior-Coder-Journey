# 🐜 蚂蚁找食物（Dijkstra）

> 给小宥宥的 Dijkstra 思维游戏——**点亮点指挥聪明蚂蚁，看它用最少步数抢到西瓜！**

## 怎么玩

1. 选关卡（🌱 4 路口 / 🌿 6 路口有陷阱 / 🌳 8 路口大挑战）
2. **点金色呼吸光的路口**（= 当前已知最近）→ 蚂蚁爬过去 → 数字牌刷新（松弛）
3. 一直点亮点，直到 🍉 西瓜亮起 → 蚂蚁到啦！
4. 结算：**莽撞蚂蚁**（只看岔路少）和聪明蚂蚁的路线画在一起对比

## 给爸爸的话（教学点）

- 金色亮点 = Dijkstra 的贪心选择（当前最近）
- 数字牌变小 = 松弛；处理过的路口变绿 = 定案
- **莽撞蚂蚁 = BFS 直觉**（岔路少≠步数少）——第 2 关开始它一定输！
- 结算彩蛋："岔路少 ≠ 步数少！"——加权的意义自己会说话
- 三关全通有庆祝 🎉
