# 🐷 小猪省钱路

> 给小宥宥的 Dijkstra 思维游戏——**每次都去最便宜的一站，价格面板自己会更新！**

## 怎么玩

- 🍼 **宝宝模式**：小猪从 🏠 家去 🏫 学校，点相邻的路走，数硬币——试试哪条路最省！
- 🚀 **挑战模式（Dijkstra 操作台）**：
  1. 每个站有个**价格面板**（数字/∞）
  2. 每次点**价格最小的站**（贪心！）→ 它定案 ✅
  3. 到了新站，邻居的价格可能**变小**（松弛）——看看面板刷新！
  4. 直到学校定案 → 总价就是最短路径！

## 给爸爸的话（教学点）

- 贪心（选最便宜）+ 松弛（更新邻居）+ 定案（✅不再变）= Dijkstra 三步
- 结算彩蛋："如果有一条路'倒贴钱'（负权），这个方法会失灵——现实世界没有这种路"
- 宝宝模式结算会画**最优路线金线**，和孩子的路线对比
- 问孩子："为什么选了最贵的路，小猪会多花钱？"——他自己数出来的
