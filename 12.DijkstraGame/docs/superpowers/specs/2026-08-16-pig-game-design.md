# 《小猪省钱路》设计文档

- 日期：2026-08-16
- 状态：已批准（算法森林系列 · 第 7 章 Dijkstra）
- 项目：Junior-Coder-Journey / 12.DijkstraGame

## 1. 一句话定位

> 小猪要从家去学校，每条路要付"硬币"。孩子手动跑 Dijkstra：
> 每次去"当前最便宜的一站"，看价格面板刷新（松弛），直到终点。
> 贪心 + 松弛 + 定案 = 孩子亲手做的三件事。

## 2. 核心动作（跟着算法走）

- 挑战模式：**选站（贪心）→ 面板更新（松弛）→ 定案 ✅** 三步循环
- 宝宝模式：手动选路数硬币，找到最省的路（最优对比）
- 终点定案：最短路径金线 + 总价揭晓

## 3. 双模式

| | 🍼 宝宝模式 | 🚀 挑战模式 |
|---|---|---|
| 图 | 4-6 节点，边权 1-6 硬币 | 5-8 节点，边权 1-9 硬币 |
| 玩法 | 点邻居站走路径，累计硬币 | **完整 Dijkstra**：从面板选最便宜的未定案站 |
| 错误 | 无（随便走，结算对比最优） | 选错站（非面板最小）→ 提示 |
| 结算 | 总价 vs 最优（金线对比） | 总价 = 终点面板价（必然最优）+ 最短路径金线 |
| 星级 | 总价=最优 3⭐ / ≤最优+2 2⭐ / 其他 1⭐ | 0 错 3⭐ / ≤2 错 2⭐ / 其他 1⭐ |
| 纪录 | localStorage 最少总价 | localStorage 最少错误 |

## 4. 教学点

- 贪心：每次选最便宜 = Dijkstra 的"下一站"
- 松弛：到了新站，邻居的面板数字可能变小（"3+2=5 < 6，更新！"）
- 定案：处理过的站 ✅ 不再变（非负权保证）
- 结算彩蛋：负权边（倒贴钱的路）会让 Dijkstra 失灵——现实世界没有这种路
