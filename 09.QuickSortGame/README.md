# 📚 书架整理员

> 给小宥宥的快速排序思维游戏——**抽一本标杆，分两堆，每堆再分，书架就整齐了！**

## 怎么玩（就两步）

1. **点一本书当标杆**（随便选哪本都行！）
2. **弹出书来就分堆**：点「📖 更小·放左边」或「📖 更大·放右边」

书越高数字越大——小宥宥凭高矮就能分，不用认数字。

## 给爸爸的话（教学点）

- 分完一堆，自动出现下一堆 → 孩子亲手跑**分而治之**（快排的递归）
- 标杆选得好（不高不矮）→ 分的次数少 → 结算页有对比彩蛋
- 问孩子："标杆挑中间和挑最大的，哪个快？"——他自己玩出来
