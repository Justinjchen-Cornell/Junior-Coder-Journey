# 《书架整理员》设计文档

- 日期：2026-08-16
- 状态：已批准（算法森林系列 · 第 4 章 快速排序）
- 项目：Junior-Coder-Journey / 09.QuickSortGame

## 1. 一句话定位

> 让孩子亲手跑一遍快速排序：抽标杆 → 分两堆 → 每堆再分 → 书架排好。
> 分而治之不是比喻，是他 5 分钟里做的事。

## 2. 玩法（递归分堆）

1. **抽标杆**：当前书堆里随便点一本 → 飞到中间发光（"随便选哪本都行！"）
2. **分堆**：其余书一本本弹出，孩子点两个大按钮「小（放左）/ 大（放右）」
   - 书的高度 = 数字大小（3 岁凭高矮分堆，不用认数字）
3. **自动递归**：分完 → 左堆自动开分（右堆排队）→ 每堆只剩一本 = 排好
4. **书架**：每本书"落位"时跳上书架对应格位（value-1 槽，动画弹入）

## 3. 双模式

| | 🍼 宝宝模式 | 🚀 挑战模式 |
|---|---|---|
| 书本 | 5-7 本 | 8-12 本 |
| 计分 | 按错误（分错堆） | 错误 + **回合数**（抽标杆次数） |
| 教学彩蛋 | 分堆层级提示 | 结算对比：回合 vs 最优 ceil(log2 n)（"每次挑中间，回合少一半！"） |
| 纪录 | localStorage 最少错误 | localStorage 最少回合 |

## 4. 教学点

- 分而治之：分堆后子堆自动再分（孩子看到"大问题变小问题"）
- 标杆随便选都行（快排核心：pivot 任意）
- 标杆挑得好（中间）→ 回合少 → O(n log n) vs O(n²) 的体感萌芽
