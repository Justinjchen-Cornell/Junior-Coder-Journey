# 《猜猜它是谁》设计文档

- 日期：2026-08-16
- 状态：已批准（算法森林系列 · 第 10 章 KNN）
- 项目：Junior-Coder-Journey / 15.KNNGame

## 1. 一句话定位

> 森林里来了个新动物 ❓——看它在特征图上离谁最近，选 K 个邻居，投票猜它是哪一族！
> 距离 = 相似度；K 太小听噪声，K 太大抹边界——孩子自己试出来。

## 2. 核心机制（一个交互）

- 特征图：x = 大小，y = 毛茸茸程度；已知动物按族分布（🐰 蹦蹦族 / 🐢 慢慢族 / 🦊 跑跑族）
- 孩子点已知动物 → 选中为邻居（画距离线 + 距离数）→ 最多 K 个 → 可取消重选
- K 选择（L3 可调 1/3/5；L1/L2 固定 3）
- 点「投票」选族（3 选 1）→ 揭示正确答案（= 真·最近 K 个的多数）

## 3. 三关递增（陷阱 = 设计出来的）

| 关 | 结构 | 教学 |
|---|---|---|
| 1 | 2 族 8 只，目标深在兔族 | 看最近邻居（K=3 固定） |
| 2 | 2 族 + **噪声邻居**（龟族离目标最近） | **K=1 会错，K=3 才对**——"别看单个最近的" |
| 3 | 3 族 + K 可调（1/3/5） | K 敏感实验："1 个听噪声，3 个刚刚好，5 个抹边界" |

- 正确答案 = 真最近 K 个的投票多数（距离欧氏）
- 星级：邻居选对（=真最近K集合）且投票对 = 3⭐；投票对但邻居选错 或 邻居对但投错 = 2⭐；其他 1⭐

## 4. 视觉（一次设计到位）

- SVG 散点图：动物 emoji + 族色环；目标 ❓ 发光
- 选中邻居：目标到动物的距离线 + 距离数角标
- 投票按钮（族 emoji 3 选 1）；结算：你的邻居 vs 真最近邻居 + 投票结果

## 5. 结算与纪录

- 你选的邻居（线） vs 正确答案的邻居（金线）对比
- "K=1 听噪声 / K=3 刚好 / K=5 抹边界" 彩蛋（L3）
- 每关纪录（错误数）；三关全通庆祝；回游乐场 + 奖励评价

## 6. 技术（系列同构 + 版本化文件名）

- js/game.1.0.js：`createKnnGame(level)` → `toggleNeighbor(id)/setK(k)/vote(cls)/getStats()/reset()`
- 距离欧氏；真最近 K 计算；手工坐标（可测）
- 单元测试 + Edge 冒烟；门户卡片点亮（第 10 个，系列完结！）

## 7. 成功标准

- 孩子能独立通关三关，L2 发现"最近的一个可能是噪声"
- 玩完能说"看最近的那几个（K 个），不能只看一个"
- 单元测试全绿 + 冒烟全过 + Pages 可玩
