# 《猜猜它是谁》实现计划

**Goal:** KNN 游戏——特征图选邻居投票，噪声陷阱 + K 可调。
**Architecture:** 系列同构：game.1.0.js 纯逻辑 TDD + ui.1.0.js SVG + 版本化文件名。

## Global Constraints
- 零依赖；全中文；大按钮；版本化文件名（style.1.0.css）
- 三关：2族8只 / 2族+噪声 / 3族K可调
- 正确答案 = 真最近K多数；L2/L3 陷阱：K=1 结果 ≠ K=3 结果
- 星级：邻居+投票双对 3 / 单对 2 / 其他 1
