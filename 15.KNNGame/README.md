# 🔮 猜猜它是谁（KNN）

> 给小宥宥的机器学习入门游戏——**看 ❓ 离谁最近，选 K 个邻居，投票猜它是哪一族！**

## 怎么玩

1. 选关卡（🌱 2 族 / 🌿 有噪声 / 🌳 3 族 K 自己选）
2. 特征图上点已知动物当邻居（最多 K 个，画距离线！）
3. 点「它可能是 🐰/🐢/🦊」投票 → 揭示答案

## 给爸爸的话（教学点）

- **距离近 = 长得像**（物以类聚）——K 个最近邻居投票 = KNN
- **第 2 关陷阱**：最近的 1 个是"噪声"（龟族混进兔群）——K=1 会猜错，K=3 才对！
- **第 3 关 K 可调**：K=1 听噪声 / K=3 刚刚好 / K=5 抹边界——孩子自己试
- 结算对比：你选的邻居 vs 真·最近 K 个 + 投票结果
- 问孩子："只看最近的一个，和看最近三个，哪个稳？"——他自己玩出来的
