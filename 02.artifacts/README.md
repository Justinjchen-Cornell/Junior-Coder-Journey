# 02.artifacts · 作品库

存放"作品"，不存放"生活照"。每一件展品都要通过下面的**隐私过滤**。

## 入馆规则（发布前逐条过）

| 检查项 | 规则 |
|--------|------|
| 人物 | 不出现正脸；只露手/背影；打码后再放 |
| 环境 | 不出现幼儿园/学校/家门牌号/小区名 |
| 声音 | 不放声音文件（语录转成文字放 episodes） |
| 文件 | ScratchJr 项目 .sj、Scratch .sb3、程序截图 ✅ 随便放 |
| 命名 | `YYYYMMDD_作品名_类型`（如 `20260815_小猫过河_sj`） |

## 分类建议

- `screenshots/` — 作品截图（孩子的"画作"）
- `projects/` — 可复用的项目文件（.sj / .sb3 / .py），未来儿子自己提交的代码也在这
- `moments/` — 打码后的珍贵瞬间（每季度最多选 1 张，克制即珍贵）

## 一句话原则

> **公开展示的是孩子的作品，不是孩子本人。**
