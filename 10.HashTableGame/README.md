# 🔐 小动物储物柜（🚜 含工程队模式）

> 给小宥宥的哈希表思维游戏——**查号码、算格子、直接开柜 = O(1)！**

## 三个模式

- 🍼 **宝宝模式**：5 个柜子，查号码表开柜——每次都"一下就找到"
- 🚀 **挑战模式**：10 个柜子，两对东西挤同号柜——体验"链上翻找"
- 🚜 **工程队模式**（哈希函数直接可见）：
  - 工具贴大编号（如 🔧 扳手 137）
  - 规则：**编号去尾 = 格子号**（137 % 100 = 37）
  - 孩子先算"它该进几号格子"（三选一，陷阱=原编号！）
  - 冲突：37 和 137 挤一个格子 → 篮子里翻找
  - 每次找工具 = 算一次 + 开一次 = **O(1) 的体感**

## 给爸爸的话（教学点）

- 工程队模式 = 哈希函数本体：**编号 → %100 → 格子号**
- 冲突 = 链式寻址："篮子里翻一下"的代价
- 空间换时间：200 个格子 vs 100 件工具
- 问孩子："为什么 137 号和 37 号要挤一个格子？因为他们去尾后一样！"
