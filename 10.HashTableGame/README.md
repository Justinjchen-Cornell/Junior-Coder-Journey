# 🔐 小动物储物柜

> 给小宥宥的哈希表思维游戏——**每件东西都有柜号，查号→直接开柜→拿到了！**

## 怎么玩（就两步）

1. 看"要取的东西"（比如 🧢 帽子）
2. **查号码表**：帽子→3 号柜 → 点 3 号柜子 → 打开拿到！✅

- 🍼 宝宝模式：5 个柜子，每件东西一个柜号——**每次都一次开中（O(1)）**
- 🚀 挑战模式：10 个柜子，**有两对东西挤在同一个柜子**——打开后要在"链子"上翻找

## 给爸爸的话（教学点）

- 号码表 = **哈希表**（物品名→柜号 = 哈希函数）
- 宝宝模式：全部一次开中 = O(1) 的纯净体验
- 挑战模式：冲突柜要链上翻找 = 链式寻址的代价
- 结算彩蛋："两个东西挤一个柜子就要翻好久——柜号发得好，全都一次开中！"
- 问孩子："为什么 3 号柜里有两件东西，就要多翻几下？"——他自己体会
