# 《小动物储物柜》设计文档

- 日期：2026-08-16
- 状态：已批准（算法森林系列 · 第 5 章 哈希表）
- 项目：Junior-Coder-Journey / 10.HashTableGame

## 1. 一句话定位

> 让孩子亲手体验 O(1)：**每件东西有柜号，查号→直接开柜→拿到了！**
> 挑战模式引入"冲突链柜"，让孩子体会到"链上翻找"的慢——哈希的成与败都在手边。

## 2. 核心动作（跟着算法走）

- 号码表（物品→柜号）= **哈希函数**：孩子查表 → 记柜号 → 点柜子 → 开柜
- 直接开中 = O(1)；冲突柜 = 打开后里面挂多件 → 要在链上找目标（O(链长)）
- 结算对比："你直接开了 X 次，链上翻了 Y 次——柜号不冲突的话，全都一次开中！"

## 3. 双模式

| | 🍼 宝宝模式 | 🚀 挑战模式 |
|---|---|---|
| 柜子/物品 | 5 柜 4-5 件（**无冲突**：全 O(1) 纯净体验） | 10 柜 8-10 件（**2 对冲突**：链柜体验） |
| 交互 | 看物品→查号码表→点柜子 | 同左 + 链柜打开后点目标物品 |
| 教学点 | "一下找到 = 快！" | 冲突柜要翻找 → "柜号别挤一起" |
| 星级 | 0 错=3 / ≤2 错=2 / 其他=1 | 同左（点错柜/链上点错都算错） |
| 纪录 | localStorage 最少错误 | 同左 |

## 4. 教学点

- 号码表 = 哈希表：查表 O(1) 开柜
- 冲突 = 链式寻址：链上翻找的代价
- 结算彩蛋："哈希函数选得好，柜子不挤；选不好，全挤一个柜（像坏哈希卡死）"
